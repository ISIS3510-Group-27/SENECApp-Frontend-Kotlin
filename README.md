# SENECApp

Base mínima de la aplicación Android en Kotlin y Jetpack Compose.

## Ejecutar

Abre el proyecto en Android Studio y ejecuta el módulo `app`, o compila desde la terminal:

```sh
./gradlew assembleDebug
```

La primera vista, **Discover**, usa datos locales de muestra. Las demás vistas y la conexión al backend se añadirán en próximas iteraciones.
