# SENECApp

Base mínima de la aplicación Android en Kotlin y Jetpack Compose.

## Ejecutar

Abre el proyecto en Android Studio y ejecuta el módulo `app`, o compila desde la terminal:

```sh
./gradlew assembleDebug
```

La pantalla inicial es provisional y reproduce únicamente el estado vacío de la referencia. Las vistas de producto se añadirán en las próximas iteraciones.
